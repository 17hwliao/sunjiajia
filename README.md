# Sunjiajia / 糯糯智能桌宠

这是“糯糯桌宠”智能化升级的协作仓库。项目采用本地优先的记忆与权限设计，并允许按需接入远程模型服务。

## 协作角色

- **任务发布与验收**：定义任务、验收标准、审计实现、记录结算结论与下一轮反馈。
- **执行模型**：在独立分支完成一个明确任务，提交代码、测试结果与交付说明。
- **项目所有者**：决定模型供应商、数据来源、权限边界及是否合并变更。

## 当前路线

1. 建立 Agent 核心与受限 Tool 合约。
2. 建立本地 RAG 和记忆授权机制。
3. 接入远程 Chat、Vision、ASR、TTS Provider。
4. 在还原后的 WPF 桌宠中接入动作、语音和交互界面。

详见 [协作流程](docs/WORKFLOW.md)、[任务模板](docs/TASK_TEMPLATE.md) 和 [验收准则](docs/ACCEPTANCE.md)。

第一项可派发任务在 [TASK-001](tasks/TASK-001-agent-contracts.md)。
